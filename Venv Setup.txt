Pull the latest changes from GitHub before you start each session. 
In the VS Code terminal, at your project root:
powershell

If you have uncommitted local changes and need to pull anyway, save them first so nothing's lost:

git status              # see what's changed locally
git stash                # temporarily shelves your changes
git pull                 # now pulls cleanly
git stash pop            # brings your changes back on top

If requirements.txt was updated (the admin added a new library), reinstall after pulling so your environment matches:
